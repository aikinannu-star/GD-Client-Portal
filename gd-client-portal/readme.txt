A modular client portal for service projects, client onboarding, collaboration,
approvals, deliverables, documents, billing, support, automation, reporting,
and operational management.

== Description ==

GD Client Portal provides a client-service workflow centered on:

Intake → Onboarding → Projects → Collaboration → Approvals → Deliverables →
Billing → Support → Completion.

Advanced automation, intelligence, governance, deployment, and observability
tools support the operational lifecycle.

== Product workflow ==

* Service intake
* Client onboarding
* Project workspace
* Collaboration and communication
* Approvals and deliverables
* Documents and billing
* Support and completion

== Production operations ==

The plugin also includes runtime diagnostics, release governance, upgrade and
rollback readiness, deployment evidence, observability, and integration testing
infrastructure.

== Installation ==

1. Upload the plugin ZIP through the WordPress Plugins screen, or install it from the WordPress.org Plugin Directory after approval.
2. Activate GD Client Portal.
3. Configure the plugin settings and workflow modules required by your site.
